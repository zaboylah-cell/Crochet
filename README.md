# 🧶 Crochet — Your Little Yarn Paradise

A responsive, pastel pink and lavender crochet pattern studio with a built-in, no-API-key crochet helper.

## Features

- Search patterns by title, category, skill level, yarn, or description
- Filter by category and skill level
- Save and remove favorites (stored in this browser using localStorage)
- Detailed materials lists, step-by-step instructions, and project tips
- Surprise-me pattern picker
- Built-in crochet helper for stitch explanations, beginner advice, abbreviations, yarn and hook guidance, and pattern-specific instructions
- Mobile-friendly navigation, accessible labels, and keyboard-friendly modal
- No build tools, account, backend, or API key required

## Run locally

Open `index.html` in a modern browser. Everything is contained in one file.

## GitHub Pages

This repository is designed to publish from the `main` branch and repository root. In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, and save if Pages is not already enabled automatically.

The site uses browser local storage for favorites. Favorites are local to each browser/device and are not synced between devices.

## Notes

The built-in helper uses curated crochet knowledge and the pattern library. It is not a remote generative AI service, so it works without an API key but may not know every advanced or unusual technique. Pattern times are estimates and instructions may need adapting to your yarn, hook, and tension.
